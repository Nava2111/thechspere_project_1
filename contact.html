Frequently Asked Questions

Student & Viva FAQ

Common questions and concise answers regarding the TechSphere project structure.

TechSphere is built entirely using standard frontend technologies: semantic HTML5 for structure, Vanilla CSS3 for the custom dark technology design system and responsiveness, and Vanilla JavaScript for client-side interactions, navigation handling, and form validation. No server-side frameworks or external databases were required.

No. Because this is a 100% static frontend project, all 10 pages can be opened directly in any modern web browser (Google Chrome, Firefox, Safari, Edge) from local files, a flash drive, or any static hosting server without running Node.js, Python, or Apache.

We recommend starting with basic Web Development (HTML and CSS) to quickly see visual results, followed by foundational programming concepts in Python or C. This builds problem-solving intuition before moving into data structures or advanced frameworks.

Responsiveness was achieved using clean CSS Flexbox, CSS Grid layouts, fluid percentage containers, and custom media queries configured for tablet (max-width: 820px) and mobile phone (max-width: 480px) viewports. This ensures fast load times and clean code that is easy to explain during a viva examination.
