Cloud Computing

Understand how on-demand computing resources, global networks, and virtualized services have revolutionized modern software deployment and digital infrastructure.

Core Principle

What is Cloud Computing?

Cloud computing is the delivery of on-demand computing services—including servers, data storage, networking capabilities, databases, and software applications—over the internet ("the cloud") on a pay-as-you-go pricing model.

Instead of colleges or companies buying and maintaining physical server rooms and cooling units, they rent computing capacity from major cloud providers such as Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

Key Features of Cloud Computing

  • On-Demand Self-Service: Users can provision servers and storage automatically without manual intervention.
  • Broad Network Access: Services are accessible through standard web browsers from any device anywhere in the world.
  • Resource Pooling: Provider resources are pooled dynamically to serve multiple customers securely.
  • Rapid Elasticity: Systems can instantly scale up during traffic spikes and scale down during quiet hours.

Service Hierarchy

Three Main Cloud Service Models

Cloud offerings are traditionally organized into three layered abstraction levels: IaaS, PaaS, and SaaS.

Infrastructure

IaaS (Infrastructure as a Service)

Provides fundamental computing resources such as virtual machines, physical servers, block storage, and virtual network switches over the internet.

User Responsibility: Managing the operating system, installed software, runtimes, and application data.

Common Examples: Amazon EC2, Google Compute Engine, Microsoft Azure Virtual Machines.
Platform

PaaS (Platform as a Service)

Provides a ready-to-use development and deployment environment in the cloud. Developers focus solely on writing code while the platform manages OS patches, scaling, and web servers.

User Responsibility: Managing application source code and database configurations.

Common Examples: AWS Elastic Beanstalk, Google App Engine, Heroku, Render.
Software

SaaS (Software as a Service)

Delivers fully functioning, end-user applications hosted and operated by third-party cloud vendors accessible through web browsers.

User Responsibility: Simply logging in and using the software application without managing any servers.

Common Examples: Google Workspace (Gmail, Drive), Microsoft 365, Dropbox, Slack.
Deployment Strategies

Cloud Deployment Models

How organizations choose to position and isolate their cloud workloads.

🌐 Public Cloud

Computing infrastructure is owned and managed by third-party cloud providers and shared among multiple organizations over the public internet with logical isolation.

🏢 Private Cloud

Computing infrastructure is operated exclusively for a single enterprise, often hosted behind an on-premise firewall or a private dedicated data center for strict regulatory compliance.

🔀 Hybrid Cloud

Combines public and private clouds, bound together by standardized technology that allows data and applications to move seamlessly between them based on cost and security needs.

Key Benefits of Cloud

  • Cost Efficiency: Eliminates capital expenditure (CapEx) of physical hardware in favor of operational costs (OpEx).
  • High Availability & Disaster Recovery: Automated geo-redundant backups ensure systems stay online even during hardware failures.
  • Global Scalability: Deploy applications near users worldwide within minutes.

Cloud Career Opportunities

  • Cloud Support Associate: Troubleshooting cloud server instances and user networking issues.
  • Cloud Solutions Architect: Designing scalable and cost-effective multi-tier cloud applications.
  • DevOps Engineer: Automating continuous integration and continuous deployment (CI/CD) pipelines in the cloud.
